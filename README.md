## 🚀 Projetos em destaque

### 🤖 [AI Recruiter API](https://github.com/RafaelCicarino/ai-recruiter-api)

API REST para análise de currículos e comparação com vagas.

O sistema recebe currículos em PDF, identifica tecnologias e produz indicadores como score ATS, compatibilidade com a vaga, pontos fortes e sugestões de melhoria.

**Tecnologias:** Python, FastAPI, PostgreSQL, SQLAlchemy, Pytest, Docker, GitHub Actions e OpenAI API.

**Destaques do projeto:**

* Arquitetura organizada em camadas
* Upload e processamento de arquivos PDF
* Persistência de dados no PostgreSQL
* Testes automatizados
* Integração contínua com GitHub Actions
* Execução com Docker Compose
* Documentação interativa com Swagger
* Proteção de credenciais com variáveis de ambiente

### 📊 [Lead WhatsApp Dashboard](https://github.com/RafaelCicarino/lead-whatsapp-dashboard)

Sistema para importação e gerenciamento de planilhas de leads, com dashboard para acompanhamento de contatos comerciais pelo WhatsApp.

**Tecnologias:** Python, processamento de dados e automação de processos comerciais.

**Problema resolvido:** centralizar os leads e facilitar o acompanhamento da prospecção e dos contatos realizados.
